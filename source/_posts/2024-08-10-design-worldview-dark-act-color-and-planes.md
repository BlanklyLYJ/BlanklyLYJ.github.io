## 一、世界观:位面与规则

### 1. 位面概念

每个位面有对应的规则扰动,参考 D&D 的外层位面 + 星界位面设定。

参考视频:[我宁愿死在巴托地狱也要一睹异域风景](https://www.bilibili.com/video/BV13F4m1T7qX/)

### 2. 阵营九宫格

善良 / 邪恶 / 混乱 / 守序 / 中立 的两轴组合,这是最经典的角色动机模型。

### 3. 种族

| 类型 | 例 |
|---|---|
| 经典奇幻 | 人族、精灵(含卓尔)、兽人、亡灵、巨人 |
| 边缘类 | 提夫林(恶魔)、地精、元素 |
| 构造物 | 机械(结构造物) |
| 龙族 | 西方龙 / 东方龙(待定是否分开) |
| 死后产物 | 幽灵、契约灵(强大生物死后) |
| 外神眷属 | 星之彩、夺心魔、吉斯洋基人 |

### 4. 职业

天使、恶魔、侠盗、祭祀、巫妖、法师、先知、商人、猎人、骑士、勇士、眷族、半神、神。

### 5. 天气与时间

- 每个天气在地图对应位置出现
- 早中晚系统,某些增益在这些时间段出现

## 二、七宗罪与七美德的色彩配对

这是世界观的核心象征系统,我整理了两套配色方案。

### 方案一:从罪恶到美德(主基调)

| 罪 | 颜色 | 对应美德 | 制衡逻辑 |
|---|---|---|---|
| 傲慢(Pride) | 蓝(深) | 谦逊 | 自我优越 → 自我认知 |
| 贪婪(Greed) | 黄(浅) | 慷慨 | 占有欲 → 给予 |
| 色欲(Lust) | 红(深) | 贞洁 | 纵欲 → 节制 |
| 嫉妒(Envy) | 绿(浅) | 宽容 | 不满 → 善意 |
| 暴食(Gluttony) | 橙(浅) | 节制 | 放纵 → 自控 |
| 愤怒(Wrath) | 紫(深) | 耐心 | 暴力 → 忍耐 |
| 懒惰(Sloth) | 青(浅) | 勤勉 | 逃避 → 坚持 |

| 罪(色) | 美德(互补色) | 制衡意味 |
|---|---|---|
| 傲慢(红) | 谦逊(紫) | 高贵智慧平衡热情 |
| 嫉妒(橙) | 仁慈(蓝) | 平和中和激情 |
| 暴怒(黄) | 耐心(绿) | 成长和谐平衡冲动 |
| 懒惰(绿) | 勤勉(黄) | 阳光活力激励停滞 |
| 贪婪(蓝) | 慷慨(橙) | 热情开放化解冷漠 |
| 暴食(靛) | 节制(红) | 力量控制抑制放纵 |
| 色欲(紫) | 贞洁(靛) | 深邃纯洁冷却欲望 |

## 三、黑暗风横版 ACT:色彩剥夺的世界

### 1. 世界观:上位者剥夺了光

设定背景:

> 上位造物剥夺了世界的颜色,并用白光控制了人类。人们崇拜上位者,但因为丢失了颜色感知,加上光线偏转、幻觉、屏蔽,看不出上位者是怪物。
>
> 每个新生儿都会因为被抽离颜色感知,导致不同程度的变异。

### 2. 玩法循环:色彩回收

- 主角一开始画面是**黑白的**
- 击杀 Boss 夺取色彩,给画面染色
- 三原色(红/绿/蓝)+ 三间色 + 彩虹色,可合成 **黑色**,释放黑光
- 缺少某种颜色 ⇒ 看不见对应招式 ⇒ Boss 战难度与玩家已收集颜色绑定

这套机制把"世界观"和"玩法"绑死:剧情里的"色彩被剥夺",直接变成 Boss 战的"看不见出招"。

### 3. NG+ 的多结局

- 拿纯白 + 纯黑:发现上位者的阴谋,推翻统治
- 只拿纯黑:看见世间真相,但无法破灭上位者的迷彩,陷入绝望
- 只拿纯白:陷入幻觉,盲从上位者

### 4. 系统设计要点

| 系统 | 设计 |
|---|---|
| 战斗 | 角色连携 + AI 智能提升 + 多线叙事 + 时间流逝 |
| 怪物 AI | 反应躲开/格挡玩家技能;吸引友军;打不过会逃;高级怪逃离过多会让小兵进化 |
| NPC | 可被杀;会因角色行为产生 AI(恐惧、崇拜) |
| 国家 | 资本主义 / 宗教 / 共产主义 / 桃花源记四类对应不同社会形态 |
| 头衔 | 配合声望系统 |

### 5. 角色评级

参考博德之门 3 的"神力 / 传奇冒险家"等级分级,一般人无法登神。

## 四、技术拆解:笼中窥梦

参考 [linxinfa 的 CSDN 博客](https://blog.csdn.net/linxinfa/article/details/121683783)。

笼中窥梦(Moncage)的核心机制是**视错觉拼接**:不同面的物体在屏幕坐标系下对齐时,逻辑上"合并"为一个对象。

技术要点:

- 多个独立场景挂在不同 RenderTexture 上
- 通过摄像机角度对齐让两个物体在屏幕空间重合
- 逻辑层用一个"对齐检测器"判断合并触发
- 玩法层用这种空间错位做谜题

这种设计本质上是**用 3D 空间模拟 2D 拼图**,工程上比想象简单,但创意设计门槛极高。

## 五、角色美术技术选型:2D 帧动画 vs Spine

我做项目时整理的对比清单。

### 1. 维度对比

| 维度 | 2D 帧动画 | Spine |
|---|---|---|
| 视觉效果 | 精细,独特风格 | 偏卡通,缺手绘细腻感 |
| 概念难度 | 简单 | 学习曲线陡 |
| 资源管理 | 大量换装时困难 | 高效 |
| 新增动作成本 | 高 | 低 |
| 长期维护 | 复杂 | 低成本 |
| 低端设备表现 | 较好 | 一般 |
| 大量角色性能 | 一般 | 高效 |
| 动态修改动画 | 不灵活 | 灵活 |
| 特效细节 | 灵活 | 一般 |

### 2. 决策流程

| 项目特征 | 推荐 |
|---|---|
| 规模小,换装/动作少 | 2D 帧动画 |
| 规模大,频繁更新内容 | Spine |
| 强调独特艺术风格 | 2D 帧动画 / 混合 |
| 团队已有 Spine 经验 | Spine |
| 长期运营 | Spine |

### 3. 混合策略

- **主体**:Spine(主角 + 通用怪)
- **特效/关键场景**:2D 帧动画

### 4. 风险评估

考虑用小规模试点先验证,基于结果决定是否全量上 Spine。

## 六、玩家心流:让玩家进入状态的工程学

参考《心流》一书的笔记。心流是一种**大脑的有序状态**,即非自然状态,需要主动进入。

### 1. 进入心流的五个条件

1. **屏蔽无关干扰**:接收信息越多越杂,大脑越无序
2. **微习惯启动**:先做特别简单的事(如 5 个俯卧撑)让自己开始做事
3. **难度匹配**:事情难度处在"踮起脚尖就能碰到"的程度
4. **即时反馈**:任务列表划掉任务、半小时闹钟增强紧迫感
5. **外部环境与能量**:先睡会、喝适量水

### 2. 个人经验

不同场景下进入心流的难点不同:

- **考研复习**:难点是屏蔽干扰
- **看论文**:难点是拆解目标,避免眼高手低;给 ddl 增强威信,对自己设下的 ddl 绝对服从
- **喜欢的事**:自然进入,无障碍

### 3. 心流不止是工具,是处世哲学

> 对于绝大部分人来说,改变外在环境很难。即使如此,仍然可以从当下的事情中寻找乐趣——竞技的乐趣、人文的乐趣、创造的乐趣。让自己对眼前的事更有热情一点。

这套思路同样适用于游戏设计:让玩家在合适的难度下获得即时反馈,玩家就会进入心流,这也是黑暗风 ACT 把"色彩剥夺"做成可见难度的底层逻辑。

## 七、客户端程序的进阶方向(世界观之外)

参考知乎问题:[除了渲染,游戏客户端程序员还有哪些进阶方向?](https://www.zhihu.com/question/433768405)

整理的几个方向:

| 方向 | 技术栈 |
|---|---|
| Gameplay 框架 | ECS、状态机、行为树、HTN、GOAP |
| 网络同步 | 帧同步 / 状态同步、预测回滚、AOI、RVO |
| 工具链 | 编辑器扩展、Jenkins、Luban、Excel 导表 |
| 资源管理 | AssetBundle、YooAsset、热更 |
| 性能优化 | Profiler、内存、DrawCall、DOTS |
| AI | FSM、行为树、GOAP、Utility AI |
| 物理 | 自实现物理库 |

世界观设计偏策划,但客户端程序理解世界观能让玩法表现更到位。
