## 一、定位:野怪的轻量状态机

三套 AI 的分工逻辑(见第 3 篇 GOAP 的开篇):城镇 NPC 有整天日程可以慢慢慎思(GOAP,2s 规划),野怪只需要**战斗反应**(每帧感知,FSM 足矣)。用 GOAP 写野怪是杀鸡用牛刀——野怪没有"目标",只有"刺激-反应"。

```
Idle ──仇恨目标进入半径──► Chase ──距巢位>拴绳──► Return ──到家──► Idle
  ▲                          │ │                        │
  └──────────────────────────┘ └──贴身攻击──────────────┘
              仇恨目标再进入半径(可重新拉怪)
```

三态之外全是细节,细节全是手感。

## 二、核心规则与数值

| 项 | 数值/规则 |
|----|----------|
| 仇恨半径 | 6m(×目标潜行可见度:蹲静 1.8m/蹲动 3.6m/站 6m) |
| 拴绳半径 | 14m(距巢位超此值脱战回家,**防被风筝拉全图**) |
| 攻击距离/冷却 | 1.7m / 1.8s |
| 同族分离 | 1.1m boids 线性加权互推(防叠罗汉) |
| 回家阈值 | <0.2m |

### 2.1 目标池与粘性

- **目标池 = 存活玩家 + 存活同伴取最近**(不是只盯玩家——否则同伴永远满血站桩,倒地/扶起闭环无从触发);
- **目标粘性:新目标须近 20% 才切换**——玩家和同伴距离接近时,怪不会在两人之间高频摇摆抖动(抖动在视觉上像 AI 抽风)。

### 2.2 受击即仇恨(不用 State==Hurt 的理由)

被打的怪必有 HitStun(0.3s)——硬直分支顺手转 Chase,**受击即仇恨**。这里有个刻意的绕路:不直接检查 `State==Hurt` 判定受击,因为**怪的 Hurt 状态无人清转**(StateTransitionSystem 只驱动玩家)——用它判定会造成"回家即再仇恨"的死循环。用 HitStun 组件(有明确到期)替代状态查询——**组件的声明周期要有人管,没人管的状态不能当判定依据**。

### 2.3 潜行是玩家能力,不是怪的弱点

目标挂 StealthComponent 时按其可见度缩放仇恨判定半径;**已 Chase 的怪不受可见度影响、同伴(无组件)恒按 1.0**。潜行的语义被精确限定:影响"仇恨触发",不是隐身——脱战仍靠拴绳。这条界定防止潜行系统越权(潜行不能替代战斗逃脱机制)。

### 2.4 攻击的演出与结算分离

AttackFx(0.34s 冲刺+白闪演出)回调 TacticalCombatSystem.ApplyAttack → DamageRequest → DamageSystem——**与玩家近战/战棋同一条结算链**。回调带**入战守卫**(攻/受任一方挂战棋组件即跳过):演出 0.16s 命中窗口内 EncounterDetect 可能触发入战,不守卫会绕过 ATB 回合序对战斗单位出伤——探索/战斗两套管线的竞态窗口,用守卫焊死。

### 2.5 击退的叠加模型

怪的速度被本系统每帧覆盖,击退不能由 KnockbackSystem 直接 +=(会被下帧覆盖清零)。职责拆分:DamageSystem 受击挂 KnockbackComponent(力度 3.5、衰减 8,累计位移 ≈0.77m);KnockbackSystem 只衰减力;本系统把击退分量**并进所有速度写入值**。边角:AttackFx 演出期间受击的击退不可见(演出直写 transform),演出结束后 PositionSync 会把实体放到已积分位置——一次小跳,防双写抖动的取舍。

### 2.6 门控与入战互斥

- 输入门控期(对话/过场,IsGameplayInputBlocked)全体怪停摆(速度清零,不仇恨不攻击)——用超集判定而非只查对话,未来 Cutscene/WorldMap 接入同样生效;
- 入战(挂 BattleStateComponent)→ 本系统跳过(战棋期间归战斗管线);战斗结束组件清理后恢复探索行为(巢位仍指旧家,自然走回)。

## 三、玩家体验走查

1. 蹲伏静止接近狼(仇恨判定 1.8m):贴到 2m 它没发现——潜行有效;
2. 起身走近:6m 内狼转头逼近(Chase);
3. 且战且退把狼拉出 14m:狼停追,转身回巢(拴绳)——你打出"脱离仇恨范围"的策略空间;
4. 引两只狼:它们逼近时相互挤开(分离力),在你周围散开站位,不叠成一条影;
5. 打了就跑:被击中的狼必追(受击即仇恨),但拉过拴绳它还是回家。

## 四、系统关联

**上游**:输入门控、潜行组件(可见度)、DamageSystem(受击/击退)。
**扇出**:同伴系统(目标池互扩展)、MeleeAttack(玩家攻击目标筛选用 MonsterBrainComponent 兼作"战斗实体"标识——排除 GOAP NPC 与同伴)、实时接战(仇恨贴身即开战)。
**联动**:AttackFx 与玩家/同伴同链路(演出资产三方复用)。

## 五、设计取舍记录

**取舍一:拴绳 14m 而非无限追击**。无限追击拟真但破坏探索节奏(被追全程);14m 拴绳给玩家"跑得掉"的确定性。14 的量感:略大于屏幕对角(俯视角下跑出一个屏幕即脱战)。

**取舍二:同伴进目标池但潜行不掩护同伴**。同伴无 StealthComponent 恒按 1.0 可见度——潜行是玩家动作层的能力,不自动共享给队友(要掩护队友得靠机制性的分离,不是免费隐身)。

**取舍三:同帧直算而非感知记忆**。没有"最后见到玩家的位置"记忆(很多潜行游戏有)——仇恨/脱线都是即时判定。记忆系统是潜行玩法的深水区,本作的潜行定位(接近工具,非躲避玩法)不需要。
