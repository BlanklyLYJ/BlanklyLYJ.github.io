<!-- more -->

## 一、定位:阵营级社交积分

声望记录**阵营(组织)对你的评价**——圣蔷薇王国觉得你靠谱吗?樵夫行会记得你帮过忙吗?它与好感度(个体对个体)、阵营(你的自我道德坐标)构成三层社交数据。

核心设计是 **FNV 式双轨**:Fame(善名)与 Infamy(恶名)**分别累计,互不抵消**。单轨声望(一个数,好事加坏事减)的问题是道德会计学:救十个镇民(+50)然后杀一个(−50)= 没发生过?FNV 的答案是分开记账——**善行和恶行都留案底**,两边都高的你是"风评复杂"的争议人物,而不是"中性"的无名之辈。

## 二、数据层架构裁定(本系统最值得学的一手)

**声望 = 属性系统宿主上的属性**,不建独立组件:

- 每阵营两条属性:`Rep.<FactionId>.Fame` / `Rep.<FactionId>.Infamy`,范围 0-100;
- 监视器(编辑器属性面板)、变更事件(AttributeChangedEvent)、存档(属性 Base 入档)、clamp(注册表 Min/Max)——**全部白送**;
- 命名纪律:`Rep.` 前缀 + 阵营 Id + 字段,注册表里一行登记一个阵营。

这是属性系统"任何实体都是宿主"设计的第一次大规模兑现:一个看起来需要独立组件的系统(声望),被证明只是"世界单例实体上的一组属性"。**先问"现有基建能不能表达",再决定要不要新建**——这条纪律在这里省掉了一整个组件族(声望组件/声望事件/声望存档/声望监视器)。

## 三、段位规则(纯函数派生)

```
Fame ≥60 崇敬 / ≥30 敬重 / ≥10 接纳
Infamy ≥60 死敌(不可逆) / ≥30 仇恨 / ≥10 疏远
双方皆 ≥10 → Mixed 风评复杂
优先级:Mixed > 双向取更高
```

- **段位是派生不是存储**:查询时从 Base 现算(免结算的一帧滞后)——又一个"不存可推导值"的单一真源应用;
- **死敌不可逆**:Infamy≥60 是每阵营唯一的不可逆点——调研铁则"不可逆点少而重"的落地:声望可以修复,但有些事做了就回不去。

## 四、写入与消费链

```
剧情卡 AttrDelta(声望变动事件)
→ 属性 SetBase(直接改 Base,永久值)
→ AttributeChangedEvent
→ 声望桥(hash 反查阵营)
→ 段位重算(派生)
```

**M1 消费端**(声望必须有消费端,否则是假系统——调研铁则):

- **打听 DC 8→6**(「你名声在外」——声望降低信息获取难度,叙事型消费);
- **对话门控**(条件引擎 `Rep.StRose.Fame ≥ 30` 前缀条件,声望门槛的剧情分支);
- **日志谱声望页**(玩家可见的声望记录)。

**M2 接线**:<mark>商店价格折扣(商人经济已预留折扣公式,见第 25 篇——声望的最直接数值兑现)</mark>。

M1 数值示例:玛尔塔剧情分文不取 → StRose.Fame+10 / 收谢礼 +5;布伦按皮领赏 → Foresters.Fame+8 / 留人情 +12——**同样的剧情选择,不同分支写不同阵营的声望**,选择有可见的社交后果。

## 五、调研铁则(声望设计的业界教训)

1. **蜂巢思维是最大扣分项**——同阵营 NPC 反应完全一致=全员复制品。本作的解法:**角色卡倾向标签**(第 5 篇)——势利的商人和同情的医师对你同样的 Fame 段位有不同反应,阵营给基调,个人性格给变奏;
2. **声望必须有消费端**——没有消费的声望是假系统(玩家看不见的积分毫无意义);
3. **不可逆点少而重**——每阵营 ≤1 个(死敌档)。

## 七、系统关联

**上游**:属性系统(宿主)、剧情卡(AttrDelta 触发源)、任务多结局(不同结局写不同声望)。
**扇出**:<mark>商人折扣(M2)</mark>、对话门控、打听 DC、条件引擎 rep 源。
**规划**:<mark>阵营护甲/伪装(穿外袍临时匿名,具名 NPC 识破——M3)</mark>、<mark>两层合成(NPC 态度=阵营基调+个人偏移)</mark>、<mark>击杀 Infamy(M2 目击者检测)</mark>。

## 八、设计取舍记录

**取舍一:属性宿主而非独立组件**(上文)——基建复用的范本。

**取舍二:段位派生而非存储**。存段位(升级时写入)要处理"跨档瞬间的通知/刷新";派生查询永远新鲜。代价是每次查询重算——一次比较运算,零成本。

**取舍三:M1 只做阵营级,个人偏移 M3**。NPC 个人对玩家的态度(个人好感)+阵营声望的合成是终态,但两层同时上会互相污染调试(M1 到底是声望还是好感影响的?)——先单层跑通消费链,再加层。
