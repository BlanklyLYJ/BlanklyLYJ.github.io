<!-- more -->

## 一、定位:全局通用世界事件池

随机事件系统回答"玩家不在主动做什么的时候,世界会发生什么"。用户对它的定位裁定很明确:**「不只是给夜晚,每个地方都可能遇到」**——不是夜间惊吓生成器,是全时段全地点的世界活性来源。

**设计哲学**(Angry GM 方法论,本系统最重要的理论地基):**可见因果 > 背景模拟**——玩家看不见的幕后模拟没有意义(你模拟了三百个 NPC 的日常,玩家感受到零);有效的设计是「明显被玩家选择影响的掷骰」——事件要能被玩家的状态(声望/时间/地点/过往选择)过滤,**触发概率的公平感比内容随机性重要**。

## 二、事件卡模型:声明式五要素

一张事件卡 JSON 声明:

```
何时(Triggers 多选:OnWake / OnSleep / OnExplore)
何地(Conditions:条件表达式——条件引擎全谓词源可用)
多大(Weight:权重)
冷却多久(CooldownDays:游戏日)
演什么(SceneId:引用场景卡)
```

三个关键的架构红利:

- **内容与触发解耦**:演什么引用场景卡(SceneId)——**零新内容格式**,事件的内容生产直接复用剧情卡管线与 DialogueRunner;
- **事件状态即 WorldState 变量**(`EV_<Id>_Done` / `EV_<Id>_LastDay`)——冷却/一次性天然随存档,**又一个零持久层的系统**;
- OneShot 写回后永不再出(一次性事件);MinDay 世界天龄门(前 N 天不出此事件——**前期保护**,别让第 1 天就出重口味事件)。

## 三、抽样流程

```
过滤:Triggers 匹配 → Conditions 求值 → 非 OneShot → 冷却外 → Day ≥ MinDay
→ 加权随机抽 1 → 播卡(场景卡管线)→ 写回状态
```

- OnExplore 真实 20 秒检查一次(不是每帧——探索事件的节奏是分钟级);
- **池空则无事发生——「空事件也是事件」**:M1 全局池里有一张"平安夜"保底卡(条件全通、权重极低),它保证"什么都没发生"也是一个被设计过的结果,而不是引擎 bug 的静默——**无事之夜的平安感是设计出来的**。

## 四、M1 全局池 7 张(内容清单即设计说明)

| 卡 | 触发/条件 | 机制看点 |
|----|----------|---------|
| 平安夜 | 保底全通 | 空事件的节奏控制 |
| 夜半狼嚎 | 睡眠 / 冷却 3 天 | OnSleep 挂点 |
| 白色教堂之梦 | 睡眠 / **Wil≥12 属性门** | 意志属性的事件消费 |
| 乌鸦群 | 白天 + 近森林 | 地理+时段双过滤 |
| 流动小贩 | 白天 + 冷却 5 天 | 一次性商业机会 |
| 街头流言 | 近城镇 + 冷却 2 天 | 情报来源 |
| 乞儿 | 近城镇 + **OneShot** | 写回 BeggarHelped 善行变量 + **真扣 3 金**(ItemOps TakeGold 已配,2026-09-25 核实)——「他记住了你的脸」是叙事资产 |

七张卡覆盖了三种触发(醒/睡/探索)、属性门、地理门、冷却、一次性——**M1 的内容量是刻意精简的机制验证集**,每张卡都在测一个机制维度。

## 五、系统关联

**上游**:条件引擎(Conditions 全谓词源)、WorldState(事件状态)、场景卡/DialogueRunner(内容管线)、睡觉系统(OnSleep/OnWake 挂点)。
**扇出**:<mark>快旅途中事件(M2)</mark>、<mark>命运池/事件链(M2/M3)</mark>。
**M2 方向**:<mark>可见因果(守夜行为降低夜袭事件的权重——玩家行为影响抽样池,Angry GM 哲学的落地)</mark>、<mark>命运池(事件写回 Quest 变量,发现动态委托)</mark>、<mark>FTL 式事件链(一个事件的结果开启下一环)</mark>。

## 六、设计取舍记录

**取舍一:全局池而非区域池**。区域池(每区域自己的事件表)拟真度高,但 M1 的地图内容量撑不起分区——全局池+条件过滤(近森林/近城镇)用**条件表达空间性**,区域池留到内容量达标后(M3)。

**取舍二:20s 检查而非事件驱动**。OnExplore 事件(遭遇流民/发现异象)没有天然的触发钩子(不像睡觉有 OnSleep)——轮询是唯一选择;20s 的间隔让探索事件保持"偶发性"而不会在战斗后立刻连发。

**取舍三:权重而非复杂概率模型**。稀有度分层/伪随机分布保证(PRD)等技术在长线值得做;M1 用朴素权重——**先让抽样管道跑通,分布手感等数据**。
